# NEO-GEO Romhacks

A small web app that lets you patch your own Neo•Geo ROMs with my romhacks, entirely in your browser and hassle-free. You provide your own dump, the patch is applied locally, and you can download the result in the format of your choice.

## Disclaimer
This website is vibe-coded so I can spend my limited free time making actual romhacks instead.  
Prefer doing it yourself? The IPS files are in `/public/patches`.
